## Task verification mappings (machine-readable)

This block is the **source of truth** for `make local-checks-task TASK=<n>`.
`scripts/local_checks.py` is a generic engine: it parses the fenced
`toml ce-task-verification` block below from the active release plan
(discovered from the project version lineage — this plan declares
`**Release version:** 1.0.0rc1` / development version `1.0.0-rc-dev` in its
header, matching the `1.0.0rc` lineage — overridable with `--plan`) and builds
each task's focused steps and lint targets from it. Task ids map to this
plan's RC tasks 0–7; every step is a validation step, consistent with the RC
posture (no planned implementation).

Step kinds: `pytest = [paths...]` (runner adds `-q`, `-o addopts=`, and
`--no-cov` when available; optional `pytest_args = [...]` are inserted after
the paths) and `command = "..."` (shell-split; a leading `python` resolves to
the active interpreter). `lint_targets` scopes the quick-profile Ruff
check/format steps; if omitted or empty, changed-file detection is used.
The engine fails fast with the supported id set when a task id has no mapping
here, so a `local-checks-task` verification line without a matching mapping
cannot pass.
