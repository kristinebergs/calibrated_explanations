## Global rules

- **No new deprecation cycles.** The v1.0.0-rc gate requires an empty
  active-deprecation ledger. Every ADR-039 behavior change in this milestone ships
  as a fail-fast bug fix with a CHANGELOG migration note — no `DeprecationWarning`
  may be introduced with a removal ETA. `make deprecation-closure` must remain green
  throughout.
- **Capability verification governance.** ADR-040 governs externally visible CE capability claims, requirements, TIF interfaces, tests/gates, and evidence. Capability work in this milestone must preserve the chain `ADR/Standard -> Capability claim -> Requirement -> TIF or exemption -> Test/gate/review -> Evidence`. Mondrian is one v0.11.5 application of the framework, not the framework boundary.
- **Exception classes.** Import from `calibrated_explanations.utils.exceptions`
  (canonical home; `core.exceptions` is a re-export shim — do not add new symbols
  there). Hierarchy relevant here: `ValidationError(CalibratedError)`,
  `DataShapeError(ValidationError)`, `ConfigurationError(CalibratedError)`. Always
  pass a `details=` dict.
- **Fallback visibility.** The Task 4 `mc`-drop warning follows the repository
  fallback-visibility policy: `UserWarning` + INFO log. `core/wrap_explainer.py` is
  already in `ALLOWLISTED_PATHS` of `scripts/quality/check_warning_policy.py`
  (≈L118-119); update that entry's comment to mention the new mc-drop warning so
  the allowlist stays self-documenting.
- **TDD per defect class.** Each of the six defect classes gets a regression test
  written first (failing on pre-fix code), then the fix (test passes). Tests follow
  `test_should_<behavior>_when_<condition>` naming and extend the nearest existing
  test file (`tests/capabilities/test_mondrian_contracts.py` or
  `tests/integration/core/test_wrap_*.py`) before creating new files. Seed all RNG
  (repo convention: seed 42); no network, no wall clock.
- **CHANGELOG.** Every behavior change lands under `## [Unreleased]` in the same PR.

## Canonical conditional semantics (single implementation contract)

This section is normative for Tasks 2–4. If Task 1 ratification changes any error
type or message, update this section first, then implement.

### State model

For any wrapper/explainer at inference time exactly one of three conditional states
holds:

| State | Definition |
|---|---|
| `mc-configured` | `wrapper.mc is not None` (wrapper level only; the core `CalibratedExplainer` never holds `mc`) |
| `bins-calibrated` | `explainer.bins is not None` and no `mc` configured |
| `global` | `explainer.bins is None` |

The calibration category vocabulary is always
`np.unique(np.asarray(explainer.bins))` — read it from the stored calibration bins,
not from the calibrators (works uniformly for fast mode, multiclass, and restored
state).

### Inference-time resolution table

Implemented once in the shared helper (Task 2 step 1) and applied at every public
inference entry point:

| State | `bins` argument | Outcome |
|---|---|---|
| mc-configured | `None` | derive: `mc.apply(x)` if `isinstance(mc, MondrianCategorizer)` else `mc(x)`; then normalize + validate like explicit bins |
| mc-configured | provided | raise **E3** |
| bins-calibrated | `None` | raise **E1** |
| bins-calibrated | provided | normalize + validate (length, vocabulary) → return |
| global | `None` | return `None` |
| global | provided | raise **E2** |

Normalization (applies to provided and mc-derived bins): `arr = np.asarray(bins)`;
if `arr.ndim == 0` → `arr = np.full(x.shape[0], arr.item())` (scalar broadcast,
matching existing `IntervalRegressor.predict_probability` behavior); if
`arr.ndim > 1` → `arr = arr.reshape(-1)`; pandas Series are covered by `asarray`.
Then: length check (**E5**), vocabulary check (**E4**).

### Calibrate-time channel algorithm (Task 3 owns this)

Inside `WrapCalibratedExplainer.calibrate`, in order:

1. `channels = [kwargs.get("bins") is not None, mc is not None, reuse_conditional]`;
   if more than one is truthy → raise **E6**.
2. If `reuse_conditional`: if `self.mc is None` → raise **E7**; else set
   `mc = self.mc`.
3. If `mc is not None`: store `self.mc = mc`; compute
   `kwargs["bins"] =` normalized `mc.apply(x_cal_local)` / `mc(x_cal_local)`;
   length must equal `len(x_cal_local)` (**E5**).
4. Elif `kwargs.get("bins") is not None`: `self.mc = None`; normalize; length must
   equal `len(x_cal_local)` (**E5**). No vocabulary check at calibrate time — the
   calibration call *defines* the vocabulary.
5. Else (no channel): `self.mc = None`; `kwargs["bins"] = None` → global
   calibration. **This reset is the D4 default and is the fix for defect class 6.**

### Error table

All errors include `details=`. Message templates may be reworded at implementation
time but MUST name the same facts.

| ID | Type | Trigger | Message must state | `details` keys |
|---|---|---|---|---|
| E1 | `ValidationError` | bins-calibrated, inference without `bins` | explainer was calibrated with Mondrian bins; pass `bins=` with one category label per instance; `reuse_conditional=True` recalibrates conditionally on new data; plain `calibrate()` returns to global | `n_instances`, `requirement` |
| E2 | `ConfigurationError` | global calibration, inference with `bins` | explainer was not calibrated with Mondrian bins so conditional output is unavailable; calibrate with `bins=` or `mc=` first | `requirement` |
| E3 | `ConfigurationError` | mc-configured, inference with explicit `bins` | the configured Mondrian categorizer derives bins automatically; remove `bins=` or recalibrate without `mc` | `conflict` |
| E4 | `ValidationError` | resolved bins contain labels outside calibration vocabulary | the unknown labels (sorted) and the known vocabulary (sorted) | `unknown_labels`, `known_labels` |
| E5 | `DataShapeError` | `len(bins) != len(x)` (inference) or `!= len(x_cal)` (calibrate) | both lengths | `bins_length`, `n_samples` |
| E6 | `ValidationError` | more than one of `bins`/`mc`/`reuse_conditional` at `calibrate` | the channels supplied; exactly one allowed | `provided`, `requirement` |
| E7 | `ValidationError` | `reuse_conditional=True` with no stored `mc` | inline-`bins` calibration cannot transfer (labels are aligned with the previous calibration set); pass fresh `bins=` | `requirement` |

Note on ADR alignment: `DataShapeError` subclasses `ValidationError`, so E5
satisfies ADR-039 D3's "CE exceptions" requirement while matching the established
length-error type used in `interval_regressor.py`. Task 1 ratification confirms
this table verbatim (it currently matches ADR-039 D2/D3/D4 as drafted).
