# v1.0.1 Plan

> **Release version:** `1.0.1`
> **Development version:** `1.0.1-dev`
> **Status:** Active
> **Theme:** Post-v1.0 stabilisation

## Outcome

Confirms that the v1.0.0 GA baseline (docstring coverage, Standard-001
nomenclature, caching/parallel telemetry) is still clean after the release
planning and tooling simplification below, then ships `1.0.1`. No new runtime
behavior for users; maintainers get a release-planning surface with a single
source of truth per concern (GitHub issues for proposed work, GitHub
milestones for approved scope, this file for active-release coordination) and
release automation that no longer parses or rewrites roadmap prose.

## Excluded

- Any new public API, plugin category, or runtime behavior change.
- Caching/parallel on-by-default graduation (stays opt-in per ADR-003/ADR-004
  pending a clean telemetry sweep under T3).
- `auto_encode='auto'` wrapper preprocessing, `transform_to_numeric`
  deprecation, ranking-semantics consolidation, and plugin-author diagnostics
  — none are approved for this milestone; file or link a GitHub issue before
  scheduling any of them into a future milestone.

  deferred with maintainer approval.
