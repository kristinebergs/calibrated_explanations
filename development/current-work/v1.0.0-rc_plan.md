## 0b) ADR-038 public API graduation

### 0b.0 Goal

Close ADR-038 for `1.0.0rc1`. Promote stable non-experimental parameters to explicit named parameters. Resolve the multi-label spelling ambiguity. Implement and test the unknown-kwarg policy. Retain `**kwargs` only where there is a deliberate experimental, plugin, or internal extension seam.

The final API policy (decision D3/D4):
- Stable, non-experimental public parameters must be explicit named parameters, not hidden in `**kwargs`.
- Experimental parameters may remain in `**kwargs` but must have an `experimental:` docstring tag and must not be presented as stable v1 API.
- `multi_labels_enabled` is experimental and may remain in `**kwargs`, but no alias under any other spelling may exist unresolved before RC (decision D4).
- Unknown public kwargs must not silently disappear. Either emit a warning or fail fast; the chosen behaviour must be documented and tested.
