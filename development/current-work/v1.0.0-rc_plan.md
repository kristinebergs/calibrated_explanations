## Global rules

- **No implementation.** Every task in this plan is a verification or publication task. "Implement" language in the checklist means "verify the implementation exists and is correct," not "write new code."
- **Emergency patch exception.** If a release-blocking defect is found, the fix is written and merged as an emergency patch (separate PR, full gate re-run). The defect and fix must be recorded in the release notes under "Release-blocking defect patches."
- **Gate before tagging.** All six task checklists and the release preparation checklist must be complete before the RC tag is cut.
- **Deprecation ledger empty.** `make deprecation-closure` must report zero blocking deprecations. All active deprecations in the ledger target v1.0.0 removal (permitted) or are post-v1.0 deferrals (not RC-blocking).
