# Roadmap

Current release work is tracked in the sole active plan under
`development/current-work/`.

Future work is tracked through GitHub issues and milestones.

Completed release plans are archived under
`development/finished-work/`.

Research directions are documented in
`docs/researcher/future_work.md`.

The release procedure is defined in `release.md`.

## Where to look

| What you need | Where to find it |
|---|---|
| Proposed engineering work | GitHub issues |
| Approved release scope | GitHub milestones |
| Active milestone task breakdown and release gates | `development/current-work/vX.Y.Z_plan.md` |
| Completed milestone records | `development/finished-work/` |
| ADRs governing architecture | `development/adrs/` |
| Engineering standards | `development/standards/` |
| Research directions | `docs/researcher/future_work.md` |
| Publication procedure | `release.md` |
| Development documentation map | `development/README.md` |
