# Roadmap

The evergreen master release plan for Calibrated Explanations is
`development/current-work/RELEASE_PLAN.md`. That file is the authoritative
source for OSS CE scope and milestone categories (committed, candidate,
research direction, deferred, out of scope).

`ROADMAP.md` is an entry-point pointer only — it does not enumerate versions or
milestone summaries. Version-specific details belong in milestone plan files
(`development/current-work/vX.Y.Z_plan.md`) and the master plan, not here.

## Where to look

| What you need | Where to find it |
|---|---|
| OSS CE scope and milestone categories | `development/current-work/RELEASE_PLAN.md` |
| Active milestone task breakdown and release gates | `development/current-work/vX.Y.Z_plan.md` |
| Completed milestone records | `development/finished-work/` |
| ADRs governing architecture | `development/adrs/` |
| Engineering standards | `development/standards/` |
| Development documentation map | `development/README.md` |
